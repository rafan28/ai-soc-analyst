# AI SOC Analyst

An AI-powered Security Operations Center (SOC) Analyst that analyzes security logs, detects threats, maps attacks to MITRE ATT&CK techniques, and generates incident reports.

## Features

- Log parsing
- Threat detection
- MITRE ATT&CK mapping
- AI-generated incident reports
- RAG-based security knowledge retrieval

## Tech Stack

### Frontend

- Tailwind CSS

### Backend
